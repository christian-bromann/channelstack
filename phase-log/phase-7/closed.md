# Phase 7 closed

Pull request: [christian-bromann/channelstack#32](https://github.com/christian-bromann/channelstack/pull/32), squash-merged on 2026-11-25 and tagged `phase-7-done`.

## What was built

- **The Rust SDK** (`sdks/rust`, crate `channelstack`), generated by `codegen/src/emit/rust.ts` on a runtime with the same modules as TypeScript's and Python's.
  - Handles with typed getters; every method and wait is a builder (`.send().await` or `.await`).
  - Field handles keep their wait state (`WaitState`), so `msg.thread()` is the same thread each time.
  - Every wait, retry and the launcher's start run on the one `wait_for`; patterns are regular expressions with their flags.
  - `pnpm test:rust`: clippy with warnings as errors, and its own tests.
- **Smoke parity (7.1):** the smoke scenarios run through TypeScript, Python and Rust (`scenarios/runners/rust`, through the generated `call_by_name`).
- **Jest (7.2):** dropped, the maintainer's decision ([decision 0017](../../docs/decisions/0017-no-jest.md)).
- **pytest (7.3):** `integrations/pytest-channelstack`.
  - Fixtures: `channelstack` (the client for the run), `channelstack_session` (one per test), and one per channel.
  - Checks: `expect(subject).to_…()` and `not_to_…()` with the matchers' semantics ([decision 0018](../../docs/decisions/0018-pytest-expect.md)).
  - Live mode skips what it can't run, and a refused read while describing a failure keeps it a failure (`unreported_refusals`).
  - The Slack conversation tests are ported (`test/acceptance/pytest/test_slack.py`, 14 tests) and run against the Bolt agent in the `slack` part.
- **MCP (7.4):** `channelstack mcp`, the attach commands as MCP tools over stdio.
  - Each tool calls the CLI command's own function.
  - New CLI commands: `deliveries` and `redeliver`, for every channel.
  - The skill is `skills/channelstack/SKILL.md`.
  - `test/acceptance/mcp.test.ts`: a scripted MCP client posts as a person it creates, reads Bolt's reply, tails, lists and redelivers.
- **Found on the way:**
  - The Python emitter split capital runs (`open_d_m`); it's `open_dm` now.
  - `pnpm typecheck` ran pyright without a config, so the Python SDK is now checked in the strict mode its config asks for.
