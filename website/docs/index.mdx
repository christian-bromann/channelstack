# channelstack docs

The docs arrive with the first release.

channelstack is a test harness for AI agents that live in Slack, GitHub, Linear and Notion. It fakes those platforms on localhost, so your tests script people and assert on the conversation a person would see.

## What's coming

- [Getting started](/docs/getting-started): install, point your agent at channelstack, run a first test
- [Slack](/docs/slack), [GitHub](/docs/github), [Linear](/docs/linear) and [Notion](/docs/notion): what each fake covers and how to test against it
- [Live mode](/docs/live-mode): the same tests against the real platforms
- [API reference](/docs/api-reference): every fixture, actor method and matcher

In the meantime, the [home page](/) shows what a test looks like, and the [examples](/#examples) cover each platform.
