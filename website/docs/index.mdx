# Overview

channelstack tests AI agents that live in Slack, GitHub, Linear and Notion. It runs those platforms as fakes on your machine, so a test can play the people in a conversation and check what they would see.

```ts
test("a mention gets exactly one reply, in the thread", async ({ slack }) => {
  const ana = await slack.createUser({ name: "Ana" });
  const channel = await slack.createChannel({ participants: [ana, slack.app] });

  const msg = await ana.say("@my-agent summarize yesterday's incidents", { channel });

  await expect(msg.thread).toHaveReplyFrom("my-agent", { text: /incident/i });
  await expect(msg.thread).toHaveRepliesFrom(slack.app, { count: 1 });
  await expect(channel).not.toHaveChannelMessageFrom("my-agent");
});
```

The test never touches your agent. Ana's message goes into a fake Slack workspace, which delivers the event to your agent the way Slack would. Your agent answers through the Slack SDK it already uses, pointed at the fake. The matchers then read the thread.

## What you get

- **Fakes of four platforms** on localhost: Slack, GitHub, Linear and Notion, with their real APIs, webhooks, signatures, ids and error codes. Your agent runs unchanged; one environment variable per platform points it at the fake.
- **Tests that read like the conversation.** Every action belongs to the person who takes it (`ana.say(…)`, `ben.click("Approve", …)`, `mo.comment(…)`), and every check is about what a person would see.
- **Checks that wait for the agent.** Replies arrive when they arrive. Positive checks wait until they hold; negative and exact-count checks wait until the agent has gone quiet. A test never sleeps.
- **The failures that matter, on demand.** Slack's 3-second retry, redelivered webhooks, bad signatures, rate limits and dropped sockets, so you can test what happens on a bad day.
- **The same test against the real platforms.** With sandbox credentials in the environment, a test acts on a real workspace and reads the result back. It runs on the fakes for every pull request and live at night.
- **Vitest and pytest.** channelstack plugs into the test framework you already use, with fixtures and matchers. There are SDKs for TypeScript, Python and Rust, an attach CLI and an MCP server for coding agents.

## What it doesn't do

- **It doesn't run your agent.** You start the agent as usual. `channelstack env` prints the variables it needs.
- **It doesn't fake the model.** Your agent's framework has its own fake model (the AI SDK's `MockLanguageModelV4`, LangChain's `FakeListChatModel`, …), or you use a real one. The matchers check how the agent behaved, not the exact words.
- **It isn't a pixel copy of each product.** The UI shows the conversations you have with the agent as the same transcript the matchers read, next to every delivery and API call behind them.
