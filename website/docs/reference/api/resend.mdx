# Resend API

Every handle of the Resend fake: the `resend` fixture, the people and objects a test creates on it, and what they read and wait for. How to test a Resend app or agent, step by step, is in the [Resend guide](/docs/platforms/resend).

Each call is shown in every SDK's language, with its required options (the table under it lists them all). Arguments go first; options are TypeScript's trailing object, Python's keyword arguments and Rust's builder setters. The variable names are the ones the calls return elsewhere on these pages, so `user` is a `ResendUser` handle.

Besides the errors listed with each method, most methods can fail with [`action_requires`](/docs/reference/api/errors#action-requires), [`cross_workspace_credential`](/docs/reference/api/errors#cross-workspace-credential), [`fake_actor_in_live_world`](/docs/reference/api/errors#fake-actor-in-live-world), [`internal`](/docs/reference/api/errors#internal), [`invalid_argument`](/docs/reference/api/errors#invalid-argument), [`live_misconfigured`](/docs/reference/api/errors#live-misconfigured), [`live_not_allowlisted`](/docs/reference/api/errors#live-not-allowlisted), [`not_found`](/docs/reference/api/errors#not-found), [`session_not_found`](/docs/reference/api/errors#session-not-found), [`unauthorized`](/docs/reference/api/errors#unauthorized), [`unsupported_in_live`](/docs/reference/api/errors#unsupported-in-live): a bad request, a closed session, or live mode refusing or misconfigured.

### createApp()

Make another app: a team of its own, with its own address and credentials (decision 0027), or return the one made with this name and settings. Its events go to CHANNELSTACK_RESEND_APP_&lt;NAME>_WEBHOOK_URL.

<CodeGroup>

```ts title="TypeScript"

```

```python title="Python"

```

```rust title="Rust"

```

</CodeGroup>

| Parameter | Type | Required |  |
|---|---|---|---|
| `name` | `string` | yes | option |
| `domain` | `string` | no | option |

**Returns** [`ResendApp`](/docs/reference/api/resend#resendapp).

**Live:** refused with [`unsupported_in_live`](/docs/reference/api/errors#unsupported-in-live): Live, each app is a sandbox app set up by hand, and this channel has no second one yet (decision 0027).
